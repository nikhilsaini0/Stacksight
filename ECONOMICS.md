# Unit Economics

## Revenue Model

### Free Tier (Lead Generation)
- Unlimited audits
- Shareable URLs
- Basic AI summary
- **Revenue: $0** (lead capture)

### Pro Tier (Future - $29/mo per team)
- Ongoing spend monitoring
- Monthly audit reports
- Benchmark comparisons
- Slack/Teams alerts
- **Target: 5% free-to-paid conversion**

### Enterprise (Future - Custom)
- Custom integrations
- API access
- SSO
- Dedicated support
- **Target: $500-2,000/mo**

## Cost Structure

| Item | Monthly Cost |
|------|-------------|
| Vercel Hosting | $20 |
| Supabase (Pro) | $25 |
| Anthropic API | ~$50 (est. 2,500 summaries) |
| Resend Email | $20 (5,000 emails) |
| Domain | $1 |
| **Total** | **~$116/mo** |

## Key Metrics

- **CAC (Customer Acquisition Cost)**: $0 (organic) → target <$50 (paid)
- **LTV (Lifetime Value)**: $29 × 8 months = $232
- **LTV/CAC**: >4.6x (organic) → target >3x (paid)
- **Gross Margin**: ~85% (SaaS standard)

## Break-Even
- 4 Pro subscribers = covers infrastructure costs
- Target: 100 Pro subscribers within 6 months = $2,900 MRR
