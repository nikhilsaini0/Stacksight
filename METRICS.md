# Success Metrics

## North Star Metric
**Audits with savings > $100/mo** — Measures real value delivered, not vanity page views.

## Product Metrics

### Activation
- Audit completion rate (form start → results page)
- Target: > 60%

### Engagement
- Average tools per audit
- Share link click rate
- Summary generation rate

### Retention
- Return visit rate (same user runs another audit)
- Target: > 15% within 30 days

### Referral
- Share link → new audit conversion rate
- Target: > 5%

## Technical Metrics

| Metric | Target |
|--------|--------|
| Page Load (LCP) | < 2.5s |
| Time to Interactive | < 3.5s |
| API Response (audit) | < 500ms |
| API Response (summary) | < 5s |
| Uptime | > 99.9% |
| Error Rate | < 0.1% |
